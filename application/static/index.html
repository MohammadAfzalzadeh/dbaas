    دسترسی و Secretها

    ⌄

    برای تأیید دسترسی، توکن API را وارد کنید. سپس نام Secretهای حاوی اطلاعات اتصال سرویس‌ها را مشخص کنید.

    از مقدار DBAAS_API_TOKEN استفاده کنید. توکن فقط در حافظهٔ همین صفحه نگهداری می‌شود.

    فقط با فعال بودن DBAAS_ALLOW_INLINE_SECRETS در سرور قابل استفاده است.

    در این فیلدها نام Secret موجود را وارد کنید. با خالی گذاشتن فیلد، نام پیش‌فرض استفاده می‌شود؛ Secret باید پیش از راه‌اندازی ساخته شده باشد.

    منابع PostgreSQL

    ▼

    تعداد اعضای PostgreSQL و فضای دیسک هر عضو را تعیین کنید. تعداد اعضا شامل primary و replicaهاست؛ کلاستر تک‌عضوی، replica ندارد.

    Number of pods must be between 1 and 10
    Storage capacity must be at least 1 GiB

    تنظیمات پیشرفتهٔ PgCat

    ▼

    در حالت توسعه، poolهای اتصال PgCat را برای دیتابیس‌ها و کاربران موجود تعریف کنید. این تنظیمات، دیتابیس یا کاربر SQL ایجاد نمی‌کنند.

    دیتابیس‌های مورد استفاده

    دیتابیس‌های مورد استفاده

    هنوز دیتابیسی برای اتصال PgCat تعریف نشده است. برای افزودن، «افزودن دیتابیس» را انتخاب کنید.

    کاربران اتصال

    کاربران اتصال

    هنوز کاربری برای اتصال PgCat تعریف نشده است. برای افزودن، «افزودن کاربر» را انتخاب کنید.

    فضای ذخیره‌سازی MinIO

    ▼

    MinIO فضای سازگار با S3 را برای نگهداری بکاپ فراهم می‌کند. حجم دیسک آن را مشخص کنید؛ در حالت پیش‌فرض، اطلاعات ورود از Secret خوانده می‌شوند.

    Root user is required when MinIO is enabled
    Root password must be at least 8 characters MinIO requires at least 8 characters.
    Storage capacity must be at least 1 GiB
    Backup user must be different from the MinIO root user Use a separate account; WAL-G will use this user and its password.
    Backup password must be at least 8 characters MinIO requires at least 8 characters.
    Backup bucket name is required when MinIO is enabled

    بکاپ و بازیابی

    ▼

    زمان‌بندی پشتیبان‌گیری را مشخص کنید. WAL-G بکاپ‌ها و فایل‌های WAL را در مقصد تعیین‌شده ذخیره می‌کند؛ در حالت Secret، اطلاعات اتصال از Secret مربوط به WAL-G خوانده می‌شوند.

    MinIO انتخاب شده است. در حالت Secret، اطلاعات اتصال همین MinIO را در Secret مربوط به WAL-G تنظیم کنید. در حالت توسعه، اطلاعات واردشده در فرم استفاده می‌شوند.

    اطلاعات اتصال فضای S3

    S3 access key is required
    S3 secret key is required
    Valid S3 endpoint URL is required
    Backup bucket name is required
